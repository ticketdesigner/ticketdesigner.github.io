TICKET DESIGNER v7 FRESH INSTALL

1. Create/import NEW Google Sheet from TicketDesigner_Regional_Config_v7.xlsx.
2. Paste backend/regional/Code.gs into its Apps Script project and deploy as a Web App.
3. Create/import NEW Google Sheet from TicketDesigner_Workflow_v7.xlsx.
4. Paste backend/workflow/Code.gs into its Apps Script project.
5. In Workflow Apps Script, run setRegionalConfigEndpoint('YOUR_NEW_REGIONAL_EXEC_URL').
6. Deploy Workflow as a Web App.
7. Edit assets/js/app-config.js and paste the NEW Workflow and Regional /exec URLs.
8. Upload the GitHub files to ticketdesigner/ticketdesigner.github.io.
9. Sign in at https://ticketdesigner.github.io/.
10. If no events exist, authorized designers are routed to designer.html to create the first event.

Do not import previous Events/TicketTypes or Workflow tickets/vouchers into these fresh sheets.
